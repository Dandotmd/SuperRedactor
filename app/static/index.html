PII Redactor

Local only

Drop a CSV or .xlsx file here, or click to choose

The file is parsed in memory on this machine. Nothing is uploaded anywhere.

Set each column to keep, redact, or drop. Suggestions from column names are pre-filled — check every column yourself before downloading.

The ZIP holds the redacted file plus mapping.json — the key that turns fake values back into real ones. Keep it local, never share it.

Paste text that came back from an AI tool, add the mapping.json from your redaction run, and every fake value is swapped back to the original. This also happens entirely on this machine.

Open source. Runs offline. Redaction covers whole columns — PII hidden inside free-text cells is not detected, so drop those columns if in doubt.
